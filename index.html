🔵 AlphaFold Approach

  • Uses Multiple Sequence Alignments (MSAs)
  • Template-based modeling
  • Higher accuracy for well-studied proteins
  • Computationally intensive

🔴 ESMFold Approach

  • Language model-based prediction
  • Single sequence input
  • Faster predictions
  • Good for novel sequences

💻 Command Line Interface

Use these commands to analyze proteins from the terminal:

python protein_cli.py --help
python protein_cli.py analyze P01308
python protein_cli.py advanced P01308
python protein_cli.py batch proteins.txt
python protein_cli.py server --port 5001
python protein_cli.py interactive

Available Commands:

  • analyze - Single protein analysis
  • advanced - Advanced analysis with homology
  • batch - Process multiple proteins
  • server - Launch web interface
  • interactive - Interactive mode
  • create-example - Generate example file

❓ Help & Support

🚀 Getting Started:

  1. Enter a UniProt ID (e.g., P01308) in the search box
  2. Click "🔍 Search" to start analysis
  3. Wait for structures to load
  4. Explore using different visualization styles
  5. Review RMSD results and comparison

⌨️ Keyboard Shortcuts:

  • Ctrl/Cmd + K - Focus search
  • Escape - Clear search
  • Tab - Navigate sections
  • Enter - Start analysis

🔧 Troubleshooting:

Structure not loading?

  • Check internet connection
  • Verify UniProt ID is correct
  • Try a different protein
  • Refresh the page

Server issues?

  • Restart the CLI server
  • Check port 5001 availability
  • Try a different port
  • Check console for errors
